# FixedRateIRM

These contracts were migrated from the [morpho-blue-irm](https://github.com/morpho-org/morpho-blue-irm) repository, which holds their history and PRs.

## Overview

[`FixedRateIrm`](./FixedRateIrm.sol) is an interest rate model for Morpho Blue where the borrow rate of each market is set once and never changes.
